# R1 - Base de datos de la operación (OLTP)

En esta etapa creamos las tablas de la operación diaria, cargamos los datos y revisamos que todo
esté bien antes de pasar al modelo de análisis.

## Archivos

- `diagrama_er.md` y `diagrama_er.png` - el diagrama de las 15 tablas.
- `reglas_negocio.md` - las reglas con las que funciona la tienda.
- `consultas_r1.sql` - nuestras consultas de revisión.
- `ejecutar_r1.bat` - corre todo con doble clic (scripts 01, 02 y 03 del profesor y nuestras consultas).
- `salidas/salida_r1.txt` - lo que salió al correrlo.
- `analisis_r1.md` - qué encontramos.

## Cuándo damos R1 por terminada

- Los 4 controles del script 03 dan 0.
- Las 15 tablas tienen la cantidad de filas que dice la guía.
