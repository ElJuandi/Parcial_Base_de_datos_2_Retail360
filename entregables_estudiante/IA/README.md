# Registro de uso responsable de IA

Principios del curso: **aumentar, no sustituir el razonamiento** · **validar resultados con SQL y evidencia** ·
**documentar prompts y decisiones** · **mantener autoría y trazabilidad**.

Protocolo obligatorio (guía, sección 10.1):
1. Intento propio documentado antes de consultar a la IA.
2. Prompt explícito con objetivo, contexto, limitaciones y criterios de aceptación.
3. Revisión de la respuesta, señalando supuestos y errores posibles.
4. Prueba empírica mediante SQL, DAX, cálculos o ejecución offline.
5. Decisión del grupo: aceptar, adaptar o rechazar, con justificación.

Cada interacción se registra en [`registro_ia.md`](registro_ia.md).
